The OfflineGPT MCP server ([OfflineGPT Connect](/cloud/run-in-the-cloud/cloud-mcp))
enables OpenCode to use the OfflineGPT capabilities your organization has made
available to you: Gmail read/search, Calendar list/create, Drive search/read,
Gmail draft creation, shared MCP connections such as Notion, Linear, Slack,
Stripe, Exa, and Context7, shared skills, and OfflineGPT Cloud resources like
skills, plugins, Collections, workers, members, roles, teams, and LLM
providers. The server exposes only `search_capabilities` and
`execute_capability`, so OpenCode searches what you can access and runs exact
capability names instead of loading hundreds of tool definitions into context.

## Server URL

```text
https://api.offlinegptlabs.com/mcp/agent
```

OAuth sign-in uses your OfflineGPT account, and the organization you pick is
pinned into the token. If you do not have an account, create a
[free OfflineGPT account](https://app.offlinegptlabs.com?mode=sign-up).

## Setup

1. Add this MCP entry to your `opencode.json` file:

   ```json
   {
     "mcp": {
       "offlinegpt": {
         "type": "remote",
         "enabled": true,
         "url": "https://api.offlinegptlabs.com/mcp/agent",
         "oauth": {}
       }
     }
   }
   ```

2. Authenticate the server:

   ```sh
   opencode mcp auth offlinegpt
   ```

3. Finish the browser sign-in, then choose the organization OpenCode should use.

If OpenCode runs on a remote machine or SSH host, follow
[Connect OfflineGPT MCP from a remote machine](/cloud/run-in-the-cloud/connect-offlinegpt-mcp-remote-machine).

## Switch organizations

Log out, then authenticate again and pick the organization you want in the
browser:

```sh
opencode mcp logout offlinegpt
opencode mcp auth offlinegpt
```

<Note>
OpenCode is the verified OfflineGPT Connect client. Native remote MCP OAuth passed
end-to-end implementation testing.
</Note>
