title: "Work in desktop apps"
description: "Let OfflineGPT operate native apps on macOS, Windows, and Linux with Cua Driver"
---

Computer Use is a preview that runs [Cua Driver](https://github.com/trycua/cua),
an open-source driver for native apps on macOS, Windows, and Linux. The agent
reads one exact window through its accessibility tree, acts on its controls, and
checks the result. Use the built-in browser for websites and a dedicated
connection when an app provides one.

## Set up

1. Open **Settings → Library → Computer Use**.
2. If Cua Driver is missing, choose **Install Cua Driver**. OfflineGPT runs Cua's
   official installer and shows the exact command first:
   - macOS and Linux: `/bin/bash -c "$(curl -fsSL https://cua.ai/driver/install.sh)"`
   - Windows (PowerShell): `irm https://cua.ai/driver/install.ps1 | iex`

   You can also run that command in a terminal yourself, then refresh the page.
3. Choose **Enable Computer Use**. OfflineGPT adds the Cua Driver MCP server
   (named `computer-use`, running `cua-driver mcp`) and Cua's `cua-driver`
   skill to the workspace.
4. On macOS, grant **Accessibility** and **Screen Recording** to **CuaDriver**
   when macOS asks. The settings page shows `cua-driver permissions status`.
   OfflineGPT cannot grant these permissions for you.
5. Use **Run cua-driver doctor** if something does not work.

Then mention a running app in your message, for example: “In @TextEdit, review
the document in the open window and suggest clearer wording.”

## How the agent works

The `cua-driver` skill tells the agent to:

- choose one exact app window for every action;
- start with a narrow read of that window instead of a full screenshot;
- act through element tokens from that read, batching known steps;
- work in the background where the app allows it, and ask before taking over
  the foreground or your pointer;
- verify the result from a fresh read instead of trusting that an action ran.

While the agent works, Cua Driver shows an **agent cursor**: a colored second
cursor that glides to where the agent clicks or types. It never moves your own
mouse. Under **Agent cursor** on the Computer Use page you can hide it, change
its motion style, speed, and pointing, turn the halo, float, trail, and speed
glow on or off, and choose **Preview the cursor** to watch it move. Changes
apply to the next task.

Cua Driver chooses its own permission profile at startup. OfflineGPT starts it
in its default `standard` profile.

## Privacy and availability

Window content and screenshots are processed by your selected model provider
and follow your conversation-retention settings. Enter passwords and handle
security prompts yourself; the agent must not approve system permission prompts
for you.

Cua Driver acts inside the apps it operates, so those apps can still save files,
send messages, or make other changes. Describe your intended task clearly and
stay present for sensitive work. To stop using it in a workspace, remove the
`computer-use` server from **Settings → Library**.
